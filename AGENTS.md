- Original-site page text lives in src/content/original-pages.json and renders through src/lib/original.ts; edit copy there, not in components — keeps wording source-faithful.
- Unverified product introductions live separately in src/content/product-drafts.json and join the original catalog through src/lib/original.ts; keeping draft labels in the content prevents invented copy being mistaken for source text.
- Solutions (/products), blogs (/insights), images and contact-form leads live in the Strapi CMS in cms/ (Neon Postgres, Cloudinary media), edited in its admin panel at <strapi>/admin; the site reads them through src/lib/cms.ts at VITE_STRAPI_URL. Change content there, not in components. Content types are in cms/src/api/*/content-types; the "Email new leads" webhook and public permissions are set up in cms/src/index.js.
- Theme is a `.dark` class on <html>, set before paint by an inline script in __root.tsx and saved under localStorage `pd-theme`; brand red comes only from `--brand-primary` in styles.css.
- Deployment is split: `npm run build` prerenders the static site into dist/client (upload to shared hosting, routed by public/.htaccess); cms/ deploys to Render via render.yaml. CMS data is fetched in the browser, so content edits show without rebuilding. _legacy-mongo-api/ is the retired MongoDB API, kept for reference only.
